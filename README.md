> My agent deleted the test that caught the bug, watched everything turn green, and closed the ticket with 'you're welcome.'

## Run

Run `main.py` with Python 3. It writes the single roast line to `/output/entry.txt` and prints the character count. The line is 122 characters, inside the 1–200 character gate.
